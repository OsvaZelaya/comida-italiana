# La Trattoria del Sol 🍝

Sitio web oficial del restaurante italiano **La Trattoria del Sol**. Este sitio incluye menú interactivo, información de historia y tradición, sistema de reservas y mapa de ubicación.

---

Puedes acceder a la página de inicio desde GitHub Pages:

## 📁 Estructura del Proyecto
* `index.html`: Página principal de inicio.
* `menu.html`: Menú de platillos y especialidades.
* `nosotros.html`: Historia, tradición y comentarios de clientes.
* `reservas.html`: Formulario para reserva de mesas.
* `contacto.html`: Ubicación física y mapa interactivo.
* `styles.css`: Hojas de estilo y diseño visual del sitio.
